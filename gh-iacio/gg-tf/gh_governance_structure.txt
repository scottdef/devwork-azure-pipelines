## Philosophy

Keep it simple. Keep it fast. Make it work.

- YAML files are the source of truth
- Terraform applies the state
- GitHub Actions orchestrates
- Everything is code, everything is versioned

## Usage

```bash
# Add a new repo
echo "repos:
  - name: new-service" >> repo-yamls/myteam-repos.yml

# Commit and push
git add repo-yamls/myteam-repos.yml
git commit -m "Add new-service repo"
git push

# PR opens, plan runs automatically
# Merge PR, apply runs automatically
```

No ceremony. No XML. No JSON. Just clean YAML and Terraform doing what they do best.
