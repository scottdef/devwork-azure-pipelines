                     THE UNIX PHILOSOPHY IN ACTION

  ┌───────────────────────────────────────────────────────────────┐
  │  "Write programs that do one thing and do it well."          │
  │                                        — Doug McIlroy         │
  └───────────────────────────────────────────────────────────────┘

  • organization.tf          → Declares desired state
  • import-org-settings.sh   → Imports existing state
  • Makefile.org             → Provides composable commands
  • GitHub Actions           → Automates the workflow
  • Plain text everywhere    → Human and machine readable
