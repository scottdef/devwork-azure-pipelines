║ RESOURCE IDENTIFIER                                               ║
╚═══════════════════════════════════════════════════════════════════╝

  Import ID: Organization login name (NOT numeric ID)
  
  Example: "acme-corp" ✓
  Example: "12345678" ✗

║ VERIFICATION COMMANDS                                             ║

  # Show Terraform state
  terraform state show github_organization_settings.this
  
  # Fetch from GitHub API
  gh api /orgs/acme-corp | jq
  
  # Compare settings
  make fetch-org-settings

╔═══════════════════════════════════════════════════════════════════╗
║ RESOURCE STRUCTURE                                                ║
╚═══════════════════════════════════════════════════════════════════╝

  resource "github_organization_settings" "this" {
    billing_email = "billing@acme.com"
    
    # Identity
    name        = "Acme Corporation"
    company     = "Acme Corp"
    email       = "hello@acme.com"
    location    = "San Francisco"
    blog        = "https://blog.acme.com"
    
    # Security (RECOMMENDED)
    default_repository_permission = "read"
    members_can_create_repositories = false
    web_commit_signoff_required = true
    
    # Advanced Security
    advanced_security_enabled_for_new_repositories = true
    secret_scanning_enabled_for_new_repositories = true
    dependabot_alerts_enabled_for_new_repositories = true
  }

╔═══════════════════════════════════════════════════════════════════╗
║ WORKFLOW INTEGRATION                                              ║
╚═══════════════════════════════════════════════════════════════════╝

  # Manual trigger
  gh workflow run org-settings.yml -f action=import
  gh workflow run org-settings.yml -f action=plan
  gh workflow run org-settings.yml -f action=apply
  
  # Auto-trigger on push to main
  git add terraform/organization.tf
  git commit -m "Update org settings"
  git push origin main

╔═══════════════════════════════════════════════════════════════════╗
║ REQUIRED PERMISSIONS                                              ║
╚═══════════════════════════════════════════════════════════════════╝

  GitHub Token Scopes:
  - admin:org (read/write org settings)
  - read:org (read org metadata)
  
  Organization Role:
  - Owner (to modify org settings)

╔═══════════════════════════════════════════════════════════════════╗
║ COMMON ISSUES                                                     ║
╚═══════════════════════════════════════════════════════════════════╝

  Q: Resource already exists in state?
  A: terraform state rm github_organization_settings.this
  
  Q: Authentication error?
  A: gh auth refresh -s admin:org
  
  Q: Settings not applying?
  A: Check your GitHub plan (some features require Enterprise)
  
  Q: Import shows all changes?
  A: Normal. Adjust organization.tf to match current state.

╔═══════════════════════════════════════════════════════════════════╗
║ ADVANCED: STATE MANIPULATION                                      ║
╚═══════════════════════════════════════════════════════════════════╝

  # Remove from state (doesn't delete in GitHub)
  terraform state rm github_organization_settings.this
  
  # View raw state
  terraform state pull | jq '.resources[] | 
    select(.type=="github_organization_settings")'
  
  # Move to module
  terraform state mv github_organization_settings.this \
    module.organization.github_organization_settings.this

╚═══════════════════════════════════════════════════════════════════╝
