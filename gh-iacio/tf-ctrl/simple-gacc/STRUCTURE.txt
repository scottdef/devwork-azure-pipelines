QUICK START (5 minutes)
========================

1. Set environment:
   export GITHUB_TOKEN="ghp_xxx"
   export GITHUB_OWNER="your-org"

2. Run setup:
   ./quickstart.sh

3. Review and apply:
   make plan
   make apply

DRIFT DETECTION SETUP (2 minutes)
==================================

1. Copy workflow:
   cp .github/workflows/drift-detection.yml .github/workflows/

2. Add secret: GH_ORG_ADMIN_TOKEN
   (Repository Settings → Secrets)

3. Enable Actions write permissions
   (Settings → Actions → General)

4. Test:
   gh workflow run drift-detection.yml -f create_issue=true
