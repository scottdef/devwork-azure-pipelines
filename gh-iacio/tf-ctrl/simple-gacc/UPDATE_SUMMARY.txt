⚡ QUICK START
==============

1. Terraform Setup (2 min):
   export GITHUB_TOKEN="ghp_xxx"
   export GITHUB_OWNER="your-org"
   ./quickstart.sh

2. Enable Auto-Remediation (2 min):
   mkdir -p .github/workflows
   cp drift-detection.yml .github/workflows/
   
   # Add secret: GH_ORG_ADMIN_TOKEN
   # (Settings → Secrets → New secret)
   
   # Enable Actions write permissions
   # (Settings → Actions → General)

3. Test:
   gh workflow run drift-detection.yml

🔧 HOW IT WORKS
===============

Every hour:
  ┌─────────────────┐
  │ terraform plan  │  Detect drift?
  └────────┬────────┘
           │
           ├─ No drift → Close any open issues → ✓ Done
           │
           ▼
  ┌──────────────────┐
  │ Create Issue     │  With plan output
  └────────┬─────────┘
           │
           ▼
  ┌──────────────────────┐
  │ terraform apply      │  Auto-remediate
  └────────┬─────────────┘
           │
           ├─ Success → Comment: ✅ + label: remediation-success
           │
           └─ Failure → Comment: ❌ + label: remediation-failed

RESULT: Self-healing infrastructure

🔐 SECURITY
===========

Auto-remediation is SAFE when:
  ✓ Terraform is single source of truth
  ✓ All changes go through IaC
  ✓ Manual changes are rare/accidental
  ✓ Team monitors drift issues

Risk mitigation:
  ✓ Full plan in issue (can review before apply)
  ✓ Full apply output in comment (audit trail)
  ✓ Can disable: skip_remediation=true
  ✓ All changes in Git history
  ✓ Rollback via Terraform state

🎛️  CONFIGURATION
==================

Schedule (edit workflow):
  # Hourly (default)
  cron: '0 * * * *'
  
  # Every 6 hours
  cron: '0 */6 * * *'
  
  # Daily at 9 AM
  cron: '0 9 * * *'

Skip auto-remediation:
  gh workflow run drift-detection.yml -f skip_remediation=true

Disable permanently:
  Remove "Terraform Apply" step from workflow

❓ FAQ
======

Q: Will this auto-apply changes I don't want?
A: Only changes in terraform.tfvars. Review issue before apply
   completes (~30 sec).

Q: What if I want to review first?
A: Use: gh workflow run drift-detection.yml -f skip_remediation=true

Q: Can I get detailed field comparison back?
A: Plan output shows all changes. Run terraform show locally for more.

Q: Is auto-remediation safe?
A: Yes, with proper IaC practices. See DRIFT_DETECTION.md security
   section.

Q: How do I disable it?
A: Remove "Terraform Apply" step from workflow file.
