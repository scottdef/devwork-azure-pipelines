📋 About Our Controls

Security controls run as GitHub Actions workflows that validate organization policies, repository configurations, and access controls. Each workflow exits with a pass or fail conclusion recorded by GitHub.

🔄 Update Frequency

Controls execute every 6 hours. This dashboard regenerates every hour, querying the GitHub Actions API for the latest results. The page auto-refreshes every 5 minutes.

📊 History & Trends

The "Last 5 Runs" column shows status lights for the five most recent workflow executions. Hover over each dot for run details. Trends are calculated by comparing recent vs. older results.
