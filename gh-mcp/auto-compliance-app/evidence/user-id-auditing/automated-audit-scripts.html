A scheduled script enumerates org members via the GitHub API and checks each profile against CLA standards (corporate email domain, display name set, SSO identity linked). On the latest run it scanned 137 members and flagged 2 for follow-up.

for u in $(gh api "/orgs/cla-org/members" --paginate --jq '.[].login'); do
  gh api "/users/$u" --jq '[.login, .email, .name] | @tsv'
done
