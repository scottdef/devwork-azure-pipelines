Findings

  • 13 of 16 active Copilot users (81%) were engaged: they accepted code or used an agentic surface (agent mode, CLI, cloud agent) on the day.

Definitions

AI cost
ai_credits_used x $0.0100 per credit (config pricing.ai_credit_usd)
active user
a Copilot-seated user with any interaction, generation, acceptance or agent use on a day
cost per merged PR
total cost in scope / merged pull requests in scope
cycle time
pull request created -> merged, in hours
engaged user
accepted code or used an agentic surface (agent mode, CLI, cloud agent) on the day
seat cost
seats x $39.00 per month x days/30 (Copilot Enterprise)

Notes and caveats

  • Teams with fewer than five Copilot-seated users are omitted from GitHub's user-teams report; users on several teams count toward each of their teams, so team rows do not sum to the scope total.
  • AI-assisted lines of code (loc_added_sum) are directional: they measure Copilot-suggested lines accepted or applied, not total output.
