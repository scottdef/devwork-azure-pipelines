Lab: render a template in the browser with Go-wasm

Documentation, not a shipped feature. The intake form above never depends on this page.

The library renders every item with Go's text/template on a runner. This page compiles the same engine to WebAssembly (lab/wasm/main.go, built with GOOS=js GOARCH=wasm go build) so a requester can preview a template against a payload before filing an issue. It is about 5 MB of wasm (about 1.3 MB gzipped on the wire) for one function, which is why it stays in the lab.





How it is built


cd lab/wasm
GOOS=js GOARCH=wasm go build -trimpath -o ../../_site/lab/render.wasm .
cp "$(go env GOROOT)/lib/wasm/wasm_exec.js" ../../_site/lab/   # Go 1.24; older: misc/wasm


The wasm module registers one function, renderTemplate(tmpl, json), returning
{out, err}. Only default, upper, lower,
join and toJSON are in its FuncMap.
