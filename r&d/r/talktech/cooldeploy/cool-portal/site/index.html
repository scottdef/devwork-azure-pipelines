How things change

  1. Push to main of an app repository: the pipeline builds an image and deploys it to dev.
  2. Open a pull request: it gets a preview of its own, removed when it closes.
  3. Everything else is a request in CoolEngOrg/issueops: promote, rolling release, roll back, settings, domains, add-ons, publishing an API, retiring an app.

Nothing on this page changes anything. It reads; requests write.
